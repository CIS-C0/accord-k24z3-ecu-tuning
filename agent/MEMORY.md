# Persistent memory rule given to the agent

Stored in the agent's memory (outside the project), applied in every session:

> **Approval each step.** Stop and ask before every next step, analysis included. Exception: updates to
> KNOWLEDGE.md and TODO.md never need approval.

Why: on a car and an ECU, an unrequested step can be expensive. The owner wanted to see and approve each move,
including what is analysed next, while keeping the knowledge base always current.
